# Iris Flower Classification

## 1. Project Overview
Iris Flower Classification is a Machine Learning project
that predicts the species of an Iris flower based on its
physical measurements.

## 2. Project Objective
The objective is to develop a classification model that
identifies three Iris flower species:
- Iris Setosa
- Iris Versicolor
- Iris Virginica

## 3. Dataset
The project uses the Iris dataset from Scikit-learn.

- Total records: 150
- Features: 4
- Target: Flower species

## 4. Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 5. Project Workflow
1. Load the Iris dataset.
2. Explore and analyse the data.
3. Check missing values.
4. Perform data visualization.
5. Separate features and target.
6. Split the dataset into training and testing sets.
7. Train a Random Forest Classifier.
8. Make predictions.
9. Evaluate model performance.

## 6. Machine Learning Algorithm
Random Forest Classifier was used to train the model.

## 7. Model Performance
- Training data: 80%
- Testing data: 20%
- Testing samples: 30
- Accuracy achieved: 90%

## 8. Conclusion
The project successfully classified Iris flower species
using a Random Forest Machine Learning model.

The model achieved 90% accuracy on the test dataset.
