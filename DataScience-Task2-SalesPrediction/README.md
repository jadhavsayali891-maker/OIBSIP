# Sales Prediction Using Python

## 1. Project Overview
Sales Prediction is a Data Science and Machine Learning
project that predicts product sales based on advertising
expenditure.

## 2. Project Objective
The objective is to analyse advertising data and develop
a Machine Learning model to predict sales.

## 3. Dataset
The project uses the Advertising.csv dataset.

- Total Records: 200
- Total Columns: 4
- Features: TV, Radio and Newspaper
- Target: Sales

## 4. Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 5. Project Workflow
1. Load the dataset.
2. Explore the data.
3. Check missing values.
4. Perform statistical analysis.
5. Create visualizations.
6. Separate features and target.
7. Split training and testing data.
8. Train a Linear Regression model.
9. Predict sales.
10. Evaluate model performance.

## 6. Machine Learning Algorithm
Linear Regression was used to train the model.

## 7. Model Performance
- Training Data: 80%
- Testing Data: 20%
- Mean Absolute Error: 1.461
- Mean Squared Error: 3.174
- Root Mean Squared Error: 1.782
- R2 Score: 0.899

## 8. New Sales Prediction
The model predicted 12.24 sales units using
new advertising budget values.

## 9. Conclusion
The project successfully implemented a Sales Prediction
model using Python and Linear Regression.

It helped demonstrate data analysis, visualization,
regression, prediction and model evaluation.
